# D M Nihal: portfolio

Single-page portfolio site built with Vite, GSAP and Lenis.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build   # outputs to dist/
```

## Deploy (Cloudflare Pages)

- Framework preset: Vite (or None)
- Build command: `npm run build`
- Build output directory: `dist`
